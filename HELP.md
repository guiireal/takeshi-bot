# Ajuda do Takeshi Bot

## Diversos

### Horóscopo

Envie `/horoscopo câncer` ou `/signo câncer` para receber a imagem do signo com a previsão semanal na legenda. Use o prefixo configurado no seu grupo.

O comando aceita Áries, Touro, Gêmeos, Câncer, Leão, Virgem, Libra, Escorpião, Sagitário, Capricórnio, Aquário e Peixes, com ou sem acentos.

O bot precisa de um [token da Spider X API configurado](./README.md#alguns-comandos-necessitam-de-api). Cada consulta bem-sucedida consome 1 request.

## IA

### Vozes especiais

O bot transforma seu texto em uma mensagem de voz usando a Spider X API. Use o prefixo do seu grupo e envie até 512 caracteres.

| Exemplo | Aliases |
| --- | --- |
| `/vozbolsonaro Bom dia, pessoal!` | `/bolsonarovoz`, `/voicebolsonaro`, `/bolsonarovoice` |
| `/vozlula Olá, tudo bem?` | `/lulavoz`, `/voicelula`, `/lulavoice` |
